> 参照库：`/Volumes/APPLE 1TB/Code/HMCL-main`（HMCL 2026 重构版分支，JavaFX 实现，含实例模型/Terracotta/NBT 编辑/Java 管理/主题包等新特性）

> RMCL 现状取自分支 `ui/home-hero-dock` 前端实测（含本套审计 02 文档的逐页功能清单）。

## 2. 缺失功能分级清单

### A 级：核心缺口（影响日常主流程，建议优先补齐）

| 功能 | HMCL 实现 | RMCL 现状 | 影响 |
|---|---|---|---|
| **服务器真实 ping/MOTD** | 主页/世界页真实查询 | 假数据卡（Home.tsx:423-480 无标识） | 首页核心信息不可信 |
| **整合包：下载/导入/更新** | 双源搜索+本地 zip/mrpack/URL 导入+更新向导 | Download 整合包 tab 纯占位（:59-65） | 主流安装方式缺失 |
| **CurseForge 源** | 双源可切换 | 源切换 chip 禁用+提示 | 最大 mod 生态不可用 |
| **世界（saves）管理** | 列表/备份/level.dat 可视化编辑/数据包/导出 zip/直进世界 | 无 | 存档管理空白 |
| **资源包/光影管理** | 实例 tab + 下载 tab + 更新检查 | 无（商店无此两类 tab） | 装扮玩法缺失 |
| **"打开目录"能力** | 右键菜单/浏览菜单多处"在文件管理器打开" | 仅"复制路径"（InstanceDetail:145-168） | 高频操作绕路 |
| **启动建议体系** | Java 版本不匹配自动纠正/自动下载、32 位提醒、loader 冲突、内存超限、缺 Java 引导 | 无（错误只发生在启动后） | 新手首启体验断崖 |
| **停止游戏/关窗确认** | 停止有确认，关闭启动器提示游戏运行中 | 5 处停止均无确认；关窗无提示；手动停止还误弹"崩溃"抽屉（ARC-18） | 误杀游戏进程风险 |
| **版本列表完整浏览** | 分类筛选+远古版本+愚人版标记+全量分页 | `slice(0,100)` 硬截断无提示 | 旧版本玩家无法安装 |
| **更新检查** | 多渠道+更新日志 Markdown 渲染 | "立即检查"永久禁用（即将推出）+ updater endpoint 占位 | 用户停留在旧版 |

### B 级：重要缺口（有替代路径或可延后，应排期）

| 功能 | HMCL 实现 | RMCL 现状 |
|---|---|---|
| authlib-injector 外置登录 | 服务器管理+引导登录+错误分类 | 仅微软/离线（国内皮肤服生态缺失） |

| 自定义离线 UUID | 输入+校验+默认生成说明 | 无 |
| 启动脚本生成 | .bat/.ps1/.command/.sh（可注入 Quick Play） | 无 |
| Quick Play（直进服务器/世界/Realms） | 设置页三模式+地址校验 | 无（后端字段也无） |
| 启动器可见性（启动后隐藏/保持/退出/随游戏退出重开） | 4 值下拉 | 无 |
| 崩溃自动分析 | 规则引擎（Java 过旧/缺 mod 名单/OptiFine 冲突/退出状态分类/环境汇总可复制） | AI 日志分析（方向不同，能力互补；但无确定性规则兜底、无环境汇总导出） |

| Mod 中文名（mcmod.cn 翻译）/Mod 更新检查 | 内置翻译数据；更新表格+批量更新+导出更新列表 | 无翻译；仅"缺失依赖扫描+补装"（RMCL 自有维度，方向不同） |

| 网络代理设置 | 系统/HTTP/SOCKS5+认证 | 无 |
| 内存下限/Metaspace UI、环境变量、前置/后置命令 UI | 均有 | 后端字段存在但 **UI 无控件**（见 §4） |
| 缓存目录自定义 | 默认/自定义+清理 | 开关+上限+清理（无自定义目录） |
| 拖拽识别多类型文件 | 整合包/NBT/json 实例清单分类处理 | 仅插件 .rmcpkg 拖拽且因 `File.path` 疑似失效（Plugins.tsx:142） |

### C 级：HMCL 独有重功能（可战略性不追，逐项显式决策即可）

- **Terracotta 联机大厅**（内置 P2P 联机、NAT 评估、核心管理）
- **NBT 编辑器**（页面级树形编辑任意 NBT）与**世界 level.dat 26.x 新格式可视化编辑**
- **主题包系统**（.hmpack 导入/导出/多主题）与背景图（网络/APNG/透明度）体系
- **便携模式**（数据随目录走）与**可运行包导出**（内嵌启动器分发）
- **结构图(Schematic)管理**、ChunkBase 种子工具集成、愚人节彩蛋

## 6. 对比结论

1. **差距的本质是"成熟度差距"而非"架构差距"**：RMCL 已具备的领域（实例管理骨架、安装向导、Modrinth 商店、账户、主题、i18n）交互质量不弱于 HMCL 对应面；缺口集中在 HMCL 十余年积累的功能面（世界/资源包/整合包/导出/Java 管理/启动建议）。
2. **优先补 A 级 10 项**即可覆盖主流程断点；B 级按用户群排期（国内用户优先 authlib-injector 与皮肤体系）；C 级建议显式决策"不做"并记录，避免无限追赶。
3. **RMCL 的差异化（AI/MCP/插件平台）已在 UI 完成度高**，应保持投入——这是对 HMCL 的结构性优势而非功能补齐。
4. 显示不完整（§4 十项）多为"后端就绪、UI 差一步"，属于性价比最高的补齐项。
