# RMCCC 前端重构验收清单

> 构建版本：`pnpm tauri build --bundles app`（前端编译期嵌入）。
> 对应设计验收基准：`docs/ui-design/13_NOTES.md §7` 与各页「验收要点」。

## 0. 启动

- [ ] 窗口弹出无白屏/透明矩形（TitleBar 正常拖动、红绿灯可用）
- [ ] 首屏为主页 Dashboard，左侧 Rail 六项 + 底部任务指示器
- [ ] 中文界面（跟随系统）无裸 key 文案

## 1. 主页 Dashboard（02）

- [ ] 无实例时：快速启动卡显示「安装游戏」引导，账号卡显示未登录
- [ ] 有实例时：大启动按钮 + 实例切换菜单（按最近游玩排序）+ 最近游玩三行
- [ ] 版本速装卡：快捷版本芯片 → 点击进入下载向导且版本已预填
- [ ] 「编辑布局」：宽度循环 / 隐藏 / 添加卡片 / 恢复隐藏 / 重置（二次确认）
- [ ] （装了 server-dashboard 样例时）插件卡片正常渲染；手动改坏插件主页不崩（error boundary）

## 2. 实例（03/04）

- [ ] 实例列表：卡片/列表切换、搜索、排序偏好刷新后保持（localStorage）
- [ ] 行内启动/停止；运行中卡片有绿色呼吸点；运行中禁止重命名/删除
- [ ] 删除实例：确认弹窗 + 「输入名称确认」
- [ ] 实例详情五个 tab 可切换且 hash 保持（#mods 刷新后仍在）
- [ ] Mod 管理：启停 checkbox（乐观更新）、添加本地文件、「检查缺失前置」→
      结果对话框 → 一键补装（纯逻辑，无需配置 AI）→ 列表刷新
- [ ] Mod 加载器：8 卡片；已装 loader 高亮「✓ 版本」；不兼容 loader 置灰有 tooltip；
      安装流程出进度（任务中心可见）
- [ ] 设置 tab：每个字段有锁图标；继承态显示「继承全局：X」；开锁后可编辑；
      保存后 `profile_list` 读回一致
- [ ] 维护：检查完整性（注明耗时）→ 修复 → 再次检查为零缺失

## 3. 下载中心（05）

- [ ] 向导四步条：版本搜索/类型过滤 → loader 卡片（Fabric 有黄条提示）→
      命名校验（重名红字）→ 安装（可离开页面）
- [ ] 安装期间去 Mod 仓库浏览，Rail 环与任务中心持续更新（非模态）
- [ ] Mod 仓库：搜索防抖、实例上下文锚条（筛选锁定）、详情页推荐版本置顶、
      安装成功 toast 带「查看实例」
- [ ] 无上下文安装：选实例弹窗 + loader 不匹配黄条警告

## 4. 账号（06）

- [ ] 零账号欢迎态（双卡片）；离线账号创建即登录
- [ ] Microsoft 设备码弹窗：大字代码 + 复制 + 打开链接按钮
- [ ] 账号切换/移除（确认文案含凭据删除说明）；**DOM 中不出现任何 token**
- [ ] 主页快速启动卡「添加账号后启动」联动（登录成功自动续启动）

## 5. 设置（08/07）

- [ ] 七个分区齐全（游戏默认/通用/下载/AI 与外部控制/插件/高级/关于）
- [ ] 语言切换即时生效；主题切换即时生效（含跟随系统）
- [ ] 下载源卡片（官方/BMCLAPI）+ 并发数可改
- [ ] **AI 服务**：输地址 → 「检测」出模型列表 → 存密钥（不回显）→ 保存并测试
- [ ] **MCP**：开启后端口/令牌显示；HTTP 配置一键复制；会话列表；
      工具权限逐条可改（默认只读/操作 allow、破坏性 confirm）；关闭态收起
- [ ] 高级-版本仓库：重新扫描 / 重命名 / 复制 / 删除（确认）

## 6. AI 与 MCP 闭环（07）

- [ ] 启动一个会崩的实例 → 异常退出自动弹日志抽屉 + 顶部红条 + 「AI 分析」高亮
- [ ] AI 分析：流式输出 → 结论卡（复制/重新分析）；未配置时按钮引导设置
- [ ] （可选，需 ZCode）复制 HTTP 配置接入 → 设置页出现会话；
      Agent 发起下载 → 任务中心行带归因 toast；Agent 请求删除实例 →
      确认卡倒计时 → 拒绝 → 无文件变化；MCP 关闭后 `lsof -i :<port>` 无监听

- [ ] 拖拽 .rmcpkg 到插件页安装；待审权限置顶红区 → 授予 → 启用
- [ ] 配置 tab：schema 表单渲染（theme-midnight / server-dashboard 样例）
- [ ] 贡献 tab 跳转主页/外观设置；逻辑 tab：compat.check 运行 + 取消
