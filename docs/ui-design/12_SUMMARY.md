# 12 · 总结与实施路线

## 1. 设计总览（一图回顾）

```
Rail: 主页 │ 实例 │ 下载 │ 账号 │ 插件 │ 设置 │（底部）任务指示器
       │      │      │      │      │      │
    卡片网格  列表→详情  向导+    设备码/  权限/    7 分区
    (可定制)  (5 tab)   Mod仓库  离线     配置/    (含版本仓库、AI 与
                                      逻辑    外部控制、插件设置页)
```

设计支柱回顾：

1. **渐进披露**贯穿每页（各页「渐进披露自查」小节是验收项）；
2. **主页 = Dashboard 卡片**（保留并强化），快速启动卡是第一焦点；
3. **下载中心**承载「装游戏本体 + Modloader + Mod」完整安装域；
4. **Mod 管理在实例下**，与 Mod 仓库双向上下文跳转（HMCL 模式）；
5. **任务非模态化**（任务中心面板 + Rail 指示器），超越 HMCL 的模态任务对话框；
6. **全接口覆盖**（86/86，15 条首次接通；`agent_*` 9 条按 ADR-013 替换为
   AI/MCP 16 条设计命令，目标面 93 条）+ 后端配套清单 15 项明确降级形态；
7. 安全/隐私（凭据不渲染、外部操作确认、插件隔离）是设计约束不是事后补丁；
8. **轻干预 · 轻 AI**（ADR-013）：不内建 Agent 平台——内部只有全局 AI 端口
   （日志分析等融入日常功能），编排交外部 AI 工具经 MCP，外部操作在 GUI 实时可见（07）。

## 3. 迁移策略

**分支重构，逐页替换，保持主干可发布**：

1. 新开 `feat/ui-redesign` 长分支；Shell/Rail/组件库先落，新路由**并行新增**
   （`/v2/…` 前缀或直接新路径 + 旧路由保留），每合入一页旧路由对应页面即可删除；
2. 全部页面完成后：删旧路由（`/login`→重定向、`/mods`→重定向已内建）、删 `app.css` 旧类、
   删 `--surface-*` 桥接变量；
3. 每阶段必须过既有门禁：`cargo fmt` / 双 clippy / `cargo test --workspace` /
   `pnpm typecheck` / `pnpm build`（注意 JS 体积趋势，见 13 §1）。

旧→新路由映射：

| 旧 | 新 |
|---|---|
| `/`（旧 Dashboard） | `/`（新 Dashboard，直接替换） |
| `/login` | `/accounts`（重定向） |
| `/settings` | `/settings`（结构重写） |
| `/instances/:id`（旧 InstanceSettings） | `/instances/:id`（重写，hash tab） |
| `/mods` | `/download#mods`（重定向） |
| `/plugins` | `/plugins`（重写） |
| `/agent` | 移除，重定向 `/settings#ai`（能力拆入设置-#ai 与任务中心，ADR-013） |

## 5. 验收标准（总）

1. `11_IPC_COVERAGE` 矩阵逐条可点通（人工脚本走查，标记 ✅；含 §1.5 设计新增面）；
2. 视觉 QA：1280×720 / 1440×900 / 2560×1440 × 亮/暗 × zh/en 全组合抽查（13 §7 清单）；
3. 六个核心用户旅程无断点：首启（装游戏→启动）、装 Mod（实例→仓库→安装→列表可见）、
   修实例（体检→修复）、换账号（切换→启动）、前置补装（检查→补装→刷新，纯逻辑无 AI）、
   外部 Agent 控制（MCP 连接→操作 GUI 可见→破坏性确认卡，依赖 P13/S4–S5）；
4. 既有工程门禁全绿 + 前端 bundle 增量 ≤ +150KB（图标 SVG + 组件库，
   见 13 §1 体积预算）。

## 6. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 后端配套（P1–P6）延迟 | 全部有灰置降级形态，不阻塞阶段验收；P4 下载卡有 PageHeader 临时按钮过渡 |
| SolidJS 大页面重写引入回归 | 逐页替换策略 + 每阶段门禁；stores 单测（事件接线逻辑抽纯函数） |
| 组件库一次性铺太大 | 阶段 A 只做 20 件核心；RmSchemaForm 等复杂件随使用页再建 |
| 旧新共存期样式冲突 | 新组件全用 `--rmccc-*`，旧类不动；桥接变量只做单向（新读旧不写） |
| i18n 双语工作量 | key 随页面提交（en+zh-CN 同 PR），禁止先写中文后补 |
| MCP 安全面（本机回环端口/令牌/外部控制） | 默认关闭 + 仅回环 + Bearer 令牌 + 逐工具权限 + 确认卡（架构文档 §5.5）；合入前安全评审（ADR-013） |
